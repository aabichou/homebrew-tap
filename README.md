# aabichou/tap

Homebrew tap for [Rezo](https://github.com/aabichou/rezo), a macOS menu bar monitor for ZLT X31 5G boxes.

```sh
brew install aabichou/tap/rezo
brew services start rezo     # launch now and at every login
```

Bottles (prebuilt binaries) are built for Apple Silicon on macOS 14 and later. On other Macs, Homebrew builds Rezo from source, which needs the Xcode command line tools.

The formula is updated automatically by Rezo's release workflow when a new version is tagged.
